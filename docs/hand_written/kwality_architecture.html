System Overview

Why DeepAgents on GCP?

The Kwality Foods pipeline is a long-horizon, multi-step workflow where a single customer order triggers production planning, quality control logging, and invoice generation — often spanning days. DeepAgents gives us: (1) a planning middleware that decomposes each order into tracked sub-tasks, (2) subagent delegation so specialized agents handle OCR, QC validation, and invoicing in isolated contexts, (3) LangGraph runtime with durable execution, checkpointing, and human-in-the-loop approval, and (4) filesystem middleware for managing batch sheets, HACCP logs, and invoice templates as working documents.

GCP-Native Stack: Cloud Run for serverless agent execution • Gemini 3 Flash for OCR (via Vertex AI) • Cloud SQL PostgreSQL for state • GCS buckets for documents • Pub/Sub + Cloud Scheduler for event triggers • Memorystore Redis for LangGraph checkpoints • Cloud Logging + LangSmith for observability.

Agent Inventory

MAIN AGENT

Orchestrator

  • Receives all event triggers (GCS uploads, Pub/Sub, Cloud Scheduler)
  • Decomposes incoming work into sub-tasks via TodoListMiddleware
  • Delegates to specialized subagents via task tool
  • Runs reconciliation checks across agents' outputs
  • Escalates to human when confidence is low or amounts exceed thresholds
  • Runs on Cloud Run with Memorystore Redis checkpointing
SUBAGENT

Order Ingestion Agent

  • OCR on handwritten order images via Gemini 3 Flash (Vertex AI)
  • Structured output extraction with response_json_schema
  • Fuzzy-matches SKU names against product catalog in Cloud SQL
  • Validates math (qty × price = line total, sum = order total)
  • Creates structured order record in Cloud SQL PostgreSQL
  • Closes Pattern 1
SUBAGENT

Production Planning Agent

  • Maps customer orders → required production batches
  • Looks up base formula + variant ingredients per SKU from Cloud SQL
  • Calculates scaled batch sizes (base × volume multiplier)
  • Checks ingredient inventory for shortages
  • Generates work order payloads for ERP
  • Closes Pattern 2
SUBAGENT

QC / HACCP Agent

  • Ingests IoT sensor data via Cloud IoT Core / Pub/Sub
  • Links readings to lot numbers and production steps in Cloud SQL
  • Validates CCP: fill temp ≥ 165°F, Brix 46±1°
  • Auto-generates timestamped HACCP execution logs (PDF → GCS)
  • Flags deviations and triggers alerts via Cloud Tasks
  • Closes Pattern 3
SUBAGENT

Invoice Agent

  • Pulls completed orders + production records from Cloud SQL
  • Converts production units (gallons) → customer units (cases/pouches)
  • Applies pricing from master price list
  • Generates invoice PDF → GCS with order/production/ship dates
  • Reconciles invoice # → order # with FK constraint
  • Closes Pattern 5

1. OCR Tool — Gemini 3 Flash via Vertex AI

# tools/ocr.py
from langchain_core.tools import tool
from google import genai
from google.genai import types
from google.cloud import storage
from pydantic import BaseModel, Field
import json

# Initialize Vertex AI client
client = genai.Client(vertexai=True, project="kwality-prod", location="us-central1")

class OrderLineItem(BaseModel):
    product_name: str = Field(description="Raw product name from handwriting")
    matched_sku: str | None = Field(default=None, description="Matched catalog SKU")
    quantity: int
    unit_price: float
    line_total: float

class OrderExtraction(BaseModel):
    customer_name: str
    order_date: str
    order_number: str
    line_items: list[OrderLineItem]
    order_total: float
    confidence: float = Field(description="0-1 OCR confidence score")

EXTRACTION_PROMPT = """Extract ALL order data from this handwritten receipt image.
Return structured JSON with: customer_name, order_date (YYYY-MM-DD),
order_number, line_items (product_name, quantity, unit_price, line_total),
and order_total. Set confidence 0-1 based on handwriting legibility."""

@tool
def ocr_order_image(gcs_uri: str) -> OrderExtraction:
    """Extract structured order data from a handwritten order photo in GCS.
    Uses Gemini 3 Flash via Vertex AI for multimodal OCR with structured output.
    Returns OrderExtraction with customer, date, line items, and totals."""

    # Download image from GCS
    storage_client = storage.Client()
    bucket_name = gcs_uri.split("/")[2]
    blob_name = "/".join(gcs_uri.split("/")[3:])
    bucket = storage_client.bucket(bucket_name)
    blob = bucket.blob(blob_name)
    image_bytes = blob.download_as_bytes()

    # Call Gemini 3 Flash with structured output
    response = client.models.generate_content(
        model="gemini-3-flash",
        contents=[
            types.Part.from_bytes(data=image_bytes, mime_type="image/jpeg"),
            types.Part.from_text(text=EXTRACTION_PROMPT),
        ],
        config=types.GenerateContentConfig(
            response_mime_type="application/json",
            response_json_schema=OrderExtraction.model_json_schema(),
            thinking_config=types.ThinkingConfig(thinking_level="medium"),
        ),
    )

    # Parse structured response
    extraction = OrderExtraction.model_validate_json(response.text)
    return extraction

2. SKU Matching Tool — Cloud SQL + pg_trgm

# tools/sku_match.py
from langchain_core.tools import tool
from sqlalchemy import create_engine, text
from google.cloud.sql.connector import Connector
from pydantic import BaseModel

connector = Connector()

def get_conn():
    return connector.connect(
        "kwality-prod:us-central1:kwality-db",
        "pg8000",
        user="agent", password=SECRET, db="kwality"
    )

engine = create_engine("postgresql+pg8000://", creator=get_conn)

class SKUMatch(BaseModel):
    raw_name: str
    matched_sku: str
    matched_name: str
    similarity: float

@tool
def match_sku(product_names: list[str]) -> list[SKUMatch]:
    """Fuzzy match handwritten product names against the catalog.
    Uses PostgreSQL pg_trgm extension for trigram similarity matching."""

    results = []
    with engine.connect() as conn:
        for name in product_names:
            row = conn.execute(text("""
                SELECT sku, name, similarity(name, :input) AS sim
                FROM products
                WHERE similarity(name, :input) > 0.3
                ORDER BY sim DESC LIMIT 1
            """), {"input": name}).fetchone()

            if row:
                results.append(SKUMatch(
                    raw_name=name, matched_sku=row[0],
                    matched_name=row[1], similarity=row[2]
                ))
    return results

5. Cloud Run Service + Pub/Sub Trigger

# main.py — Cloud Run entry point
import os, json, base64
from flask import Flask, request
from agents.orchestrator import orchestrator

app = Flask(__name__)

@app.route("/", methods=["POST"])
def handle_event():
    """Triggered by Pub/Sub push subscription.
    Events: GCS uploads, Cloud Scheduler cron, IoT sensor batches."""

    envelope = request.get_json()
    pubsub_msg = envelope.get("message", {})
    data = json.loads(base64.b64decode(pubsub_msg.get("data", "")).decode())

    event_type = data.get("type")
    if event_type == "gcs_upload":
        gcs_uri = f"gs://{data['bucket']}/{data['name']}"
        if data["name"].endswith((".jpg", ".jpeg", ".png")):
            message = f"New order photo uploaded: {gcs_uri}. Extract the order, " \
                      f"create work orders, and prepare for invoicing."
        elif data["name"].endswith(".pdf"):
            message = f"New production document: {gcs_uri}. Parse and reconcile."
        else:
            return ("skipped", 204)

    elif event_type == "daily_reconciliation":
        message = "Run daily end-to-end reconciliation across all open orders."

    elif event_type == "sensor_batch":
        message = f"Process sensor readings for lot {data['lot_number']}."

    else:
        return ("unknown event", 400)

    # Invoke with thread_id for durable checkpointed state
    thread_id = data.get("thread_id", data.get("name", "default"))
    config = {"configurable": {"thread_id": thread_id}}

    result = orchestrator.invoke(
        {"messages": [{"role": "user", "content": message}]},
        config=config
    )

    return ("ok", 200)

if __name__ == "__main__":
    app.run(host="0.0.0.0", port=int(os.environ.get("PORT", 8080)))

Phased Rollout Plan

Weeks 1–3

Phase 1: GCP Foundation + Order Ingestion Agent (Pattern 1)

Provision Cloud SQL, GCS buckets, Pub/Sub, Cloud Run. Deploy the OCR pipeline using Gemini 3 Flash via Vertex AI. Shadow mode first — agent extracts and a human verifies before data persists. Build the product catalog with pg_trgm indexes. Target: 90%+ OCR accuracy on Kwality receipts.

Weeks 4–6

Phase 2: Production Planning Agent (Pattern 2)

Connect order records to formula database in Cloud SQL and ERP. Implement batch scaling logic and inventory checks. Human-in-the-loop approval via LangGraph interrupt_on. Target: zero manual data entry for work orders.

Weeks 7–9
